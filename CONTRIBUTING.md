# Contributing to WeaR OS

## Rules

- Preserve the Snapboss duchamp tree as the device reference.
- Keep hardware fixes separate from ROM features.
- Do not add proprietary blobs to this repository.
- Run `bash scripts/validate.sh` before committing.
- Keep commits focused on one subsystem.
- Record the test performed for every functional change.

## Commit prefixes

Use prefixes such as:

    device:
    product:
    framework:
    systemui:
    settings:
    performance:
    kernel:
    build:
    ci:
    docs:
